      Import payments

      Choose a file (CSV, TSV, TXT, Excel .xlsx / .xlsm / .xls, OpenDocument .ods, Word .docx or PDF), or paste lines: name, amount, date, description. The description is optional: write it as a fourth item, or as a Description column in the file (in a calendar sheet, the third column of each day is read as the description). Dates can be 2026-11-05 or 05-11-2026. Write amounts without commas (1500) or put them in quotes ("1,500"). A header line is skipped. After choosing a file, check the rows that appear in the box before you import. The file itself is kept under Stored files.
